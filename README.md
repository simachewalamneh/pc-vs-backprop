# Predictive Coding vs Backpropagation (MNIST reconstruction)
PyTorch comparison of a predictive coding network and a backprop autoencoder (784-512-256-128-256-512-784) on MNIST, with identical architecture, weights, data order and optimizer. Includes gradient-alignment, inference-dynamics and noise-robustness experiments

One notebook that implements and compares a predictive coding network (PCN) with a backpropagation autoencoder on MNIST.

## What is compared
Both models use `784-512-256-128-256-512-784`, ReLU hidden layers, Sigmoid output, biases, identical initial weights, identical batch order, batch size 128, the same number of epochs and the same Adam optimizer. Only the learning algorithm differs.

- **Backprop autoencoder:** forward pass, reconstruction loss, chain-rule gradients.
- **PCN:** layer l-1 predicts layer l (`mu_l = f(W_l x_{l-1} + b_l)`), error `e_l = x_l - mu_l`, energy `E = 1/2 sum ||e_l||^2`. Input and output are clamped to the image, the 5 hidden states relax for T steps, and weights are updated from local errors.

## Metrics (from the task)
Reconstruction MSE, convergence over epochs, original vs reconstructed samples, training and inference time, advantages and limitations.

## Extra comparisons
1. Cosine similarity between the PC weight update and the true backprop gradient, per layer, versus inference steps.
2. How prediction error spreads across layers during PC inference.
3. Robustness to test-time input noise.

## Run
